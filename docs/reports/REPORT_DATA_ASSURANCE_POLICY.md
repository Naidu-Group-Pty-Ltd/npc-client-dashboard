# Report Data Assurance Policy

**The rule this policy exists to state:** a fact reaches a client only if the
platform can say where it came from, what it measures, at what grain and as at
when. Everything else is **unavailable** — never estimated, never generated,
never defaulted, never borrowed from a neighbouring area.

Implemented by `_shared/reports/contract/clientSafeGate.pure.ts`.

## 1. The path

```
AUTHORITATIVE SOURCE → NORMALISATION → REPORT FACT CONTRACT
  → CLIENT-SAFE DATA GATE
  → presentation / narrative / template projection / Viewer / PDF / share
```

Nothing downstream of the gate may reach around it.

## 2. The six classes

| Class | Verdict | What it requires |
| --- | --- | --- |
| **A — authoritative** | allow | observed and owned; names its source |
| **D — derived** | allow **with basis** | the basis is part of the fact; without it the figure is refused |
| **C — contextual** | allow **with grain + period** | geography grain and reference period are mandatory |
| **X — not client safe** | **block** | the label does not describe the value |
| **U — unavailable** | unavailable | no evidence held |
| **F — future source** | unavailable | planned; distinct from an absence so it is not mistaken for one |

**A classification is never silently promoted.** Strip the metadata a
`contextual` fact requires and it becomes **unavailable** — not an unqualified
figure. Changing a class means editing the register and saying why.

## 3. Blocking is by source, not by field name

A demographic fact is not unsafe because of its name. `abs_census_poa` is
trusted and a generator labelled "ABS Census 2021 estimates" is not, and both
arrive as `population`. So the gate reads **provenance**.

The test is deliberately asymmetric: a source must be **recognised** to pass.
"Not on the block-list" is not "trusted" — treating it that way would admit the
next generator by default.

| Marker in the source string | Reading |
| --- | --- |
| `estimates`, `estimated`, `perplexity`, `real-time search`, `approximation`, `synthesised` | **generated** — blocked |
| `abs_census_poa`, `abs_seifa_poa`, `rba_observations`, `report_geography`, `transport_stops`, `crime_reference` | **retrieved** — admitted |
| anything else | **unrecognised** — refused |

## 4. The register (RF-7.2A, in code)

| Fact | Why blocked |
| --- | --- |
| `market.walkScore` | a per-state constant on 1,109 of 1,114 rows |
| `market.commuteDurationMinutes` | fabricated; mean 10,125 minutes, 494 non-NSW routed to Sydney |
| `market.schoolsWithin3km` | at its ceiling on 851 of 1,114 rows |
| `market.transportQualityScore` | invented; the current service returns no score by design |
| `market.generatedDemographics` | 0 exact matches on 616 comparable rows, r = 0.04 |
| `market.hardcodedCashRate` | overstated the target by 75bp on 1,035 rows |
| `market.llmSourcedCashRate` | a model is not a statistical agency |

## 5. Two kinds of absence

**Optional** absence is suppressed — the value, the label and the row all go.
**Material** absence is explained in a deliberate sentence, written by an author,
never generated by a formatter. A report that lists what it does not know is
longer, not more honest.

## 6. The narrative bundle

A model receives values and labels only: no provenance strings, no ruling
sentences, no blocked entries. **A model that cannot see a refused fact cannot
describe one.**

Reconciliation afterwards checks **meaning as well as number** — value, source,
grain and period — because RF-7.2A established that reconciling prose against
the injected facts proves faithfulness, not truth.

## 7. Purity

Deterministic, side-effect free, no database, no network, no clock, no LLM.
Asserted by reading the modules' own source, so the property cannot decay.
